- Status: **Recommendation recorded**
- Date: 2026-07-26
- Resolves: research [#109](https://github.com/Sannrox/shikigami/issues/109)
- Contract authority: [ADR 0004](decisions/0004-v1-contract.md) (medium 1.0)
- Inputs: [#107](https://github.com/Sannrox/shikigami/issues/107) CI embed smoke,
  [#108](https://github.com/Sannrox/shikigami/issues/108) host-proof docs,
  crate `0.2.0`, tags `v0.1.0` / `v0.2.0`

## Decision question (restated)

Against the **accepted** medium 1.0 contract, is a 1.0 tag responsible now,
and if not, what ordered gaps remain?

This audit does **not** reopen thin vs medium vs broad.

## Primary recommendation

**No-go for tagging `v1.0.0` today.**

The medium contract is largely **implemented and documented** in-tree. The
blocking gap is ADR 0004’s explicit checklist item: **at least one external
embed smoke** (peer host or documented out-of-tree consumer) on the offline
path. In-repo `examples/embed_smoke.rs` + CI (#107) satisfies the **OSS
baseline** host proof, not the **external** one.

Everything else is either already green or is a **release chore** (version,
CHANGELOG, tag) that should wait until the external proof exists—or until ADR
0004 is formally amended via Design Discussion (requires [#27](https://github.com/Sannrox/shikigami/issues/27)).

## Suggested follow-up Issues (not opened by this research)

1. **feat/docs:** external offline embed smoke — minimal published consumer **or** onmyoji `Harness` dependency proof with CI artifact/link
2. **chore:** prepare `v1.0.0` release (version, CHANGELOG freeze notes, tag) — blocked on (1)
3. Only if maintainers reject external proof: **research/design** amend ADR 0004 consequences (needs #27)

## Explicit non-actions

- Do **not** tag `v1.0.0` from this closeout alone
- Do **not** widen 1.0 to require multi-host production proof (rejected “broad 1.0”)
- Do **not** drop serve/park/harvest from the freeze story (rejected “thin 1.0”)
- Do **not** treat MCP as a freeze-core surface

## Exit path chosen

**No-go** with ordered follow-ups listed above. Primary path remains medium
contract + external embed smoke, then release chore.
