# Governed path (retired)

Shikigami is a local guest. Rusui is the plane caller.

The in-tree `sekai-chisei` adapter, profile `governed`, and
`serve --intake plane` were removed. Settings that still name them fail at
resolve.

See [ADR 0024](decisions/0024-local-guest-rusui-plane-caller.md) and
[Discussion #674](https://github.com/Sannrox/shikigami/discussions/674).

For local runs: [settings.md](settings.md), [adapters.md](adapters.md),
[acp.md](acp.md).
